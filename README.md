# IROC

**Physics-Based Joint Reconstruction and Magnetic Field Mapping in Ultra-Low-Field MRI Using Reversed Readout Gradients**

This repository contains the code and (phantom) data used to produce the results in the paper above. It implements and compares several B0-inhomogeneity correction / reconstruction strategies for ultra-low-field (ULF) MRI.

## Overview

The acquisitions underlying this work are pairs of k-space datasets of the same object, collected back-to-back with **reversed readout gradient polarity** (`ROreg` / `ROinv`), optionally at a shifted echo time (`ES000` / `ES200`). Because B0 inhomogeneity displaces signal in opposite directions for the two readout polarities, the pair can be used jointly to estimate the underlying field map and to reconstruct a geometrically-corrected image.

The repository implements and benchmarks four approaches, run in order by the numbered notebooks at the repository root:

1. **Naive IFFT** (`1-IFFT.ipynb`) — direct inverse FFT reconstruction of every raw dataset, with no B0 correction, used as a baseline and as an input to the later steps.
2. **Conjugate Phase Reconstruction — CPR and Iterative CPR** (`2-CPR.ipynb`) — time-segmented CPR (`time_segmented_cpr`) using a field map estimated from the reversed-readout pair, refined iteratively (`iterative_cpr`) by alternating between field estimation and reconstruction.
3. **Image Domain Correction — IDC** (`3-IDC.ipynb`) — correction performed in image space with FSL's `topup`/`applytopup`, using the reversed-readout pair as the two phase-encode-reversed inputs `topup` expects.
4. **IROC (the proposed method)** (`4-IROC.ipynb`) — joint estimation of the B0 field, parameterized by a solid spherical harmonics (SSH) expansion (via the `sphericart` package), and reconstruction of both acquisitions, by minimizing the residual between the two readout-reversed reconstructions with PyTorch autograd/L-BFGS (`iroc_optimize_b0_ssh`, `iroc_multires`).

Distortion is then quantified for every reconstruction by non-linear (rigid + SyN) registration to a 3T reference phantom scan with **ANTs** (`5-Distortion_Computation.ipynb` and the scripts in `scripts/`), and the remaining notebooks (`6-Analysis*.ipynb`, `7-Images.ipynb`) produce the tables and figures reported in the paper.

## Repository layout

```
.
├── 1-IFFT.ipynb                      # Baseline IFFT reconstruction of all raw data
├── 2-CPR.ipynb                       # CPR and Iterative CPR reconstruction + B0 maps
├── 3-IDC.ipynb                       # Image Domain Correction via FSL
├── 4-IROC.ipynb                      # Proposed IROC joint reconstruction
├── 5-Distortion_Computation.ipynb    # Runs the ANTs-based distortion computation scripts
├── 6-Analysis1_Runtime.ipynb         # Runtime comparison across methods
├── 6-Analysis2_SSHOrder.ipynb        # Effect of SSH expansion order
├── 6-Analysis3_Distortion.ipynb      # Distortion metrics, ranking, LaTeX tables
├── 6-Analysis4_B0Maps.ipynb          # B0 map comparison across methods
├── 7-Images.ipynb                    # Other Paper figures
├── src/
│   ├── reconstruction.py             # IFFT/FFT, CPR, Iterative CPR, IROC (core algorithms)
│   ├── read_write.py                 # .h5 / .nii(.gz) I/O and XML header parsing
│   └── utils.py                      # Plotting and mask helpers used by the analysis notebooks
├── scripts/
│   ├── script_distortion_computation.py            # ANTs registration + distortion metric (per scan)
│   └── script_distortion_computation_position_avg.py  # Averages distortion metrics across positions
├── data/
│   ├── raw/                          # Raw k-space acquisitions (.h5), included
│   ├── ground_truth/                 # 3T reference phantom + segmentation labels, included
│   ├── image_domain_correction/      # topup configuration (acqparams.txt, b02b0_1.cnf), included
│   │   └── results/                  # topup outputs — generated by notebook 3
│   ├── all_reconstructions/          # Reconstructed volumes — generated by notebooks 1, 2, 4
│   ├── all_b0_maps/                  # Estimated B0 field maps — generated by notebooks 2, 4
│   ├── all_distortion_metrics/       # Distortion metrics/tables — generated by notebook 5 / scripts
│   └── all_run_info/                 # Runtimes and optimizer history — generated by notebooks 2, 4
├── pyproject.toml                    # Python project / dependency declaration
└── uv.lock                           # Locked, reproducible Python dependency versions
```

Everything under `data/` except `raw/`, `ground_truth/` and the `image_domain_correction` config files is regenerated by running the notebooks (see `.gitignore`) and is not shipped pre-populated.

## Requirements

- **Python 3.12** (see `.python-version`)
- **Python packages**, pinned in `pyproject.toml` / `uv.lock`: `numpy`, `scipy`, `torch`, `pandas`, `matplotlib`, `h5py`, `nibabel`, `scikit-image`, `sphericart`
- **Jupyter** (`jupyterlab`/`notebook`) and `ipykernel`, to run the `.ipynb` notebooks — these are not pinned in `pyproject.toml` and need to be installed separately (see below)
- **[FSL](https://fsl.fmrib.ox.ac.uk/fsl/fslwiki)**, required for `3-IDC.ipynb` — the notebook shells out to the `fslmerge` and `topup` command-line tools, so FSL must be installed and on your `PATH`
- **[ANTs](https://github.com/ANTsX/ANTs)**, required for `5-Distortion_Computation.ipynb` and the scripts it calls — these shell out to the `ResampleImage`, `N4BiasFieldCorrection`, `antsRegistration` and `antsApplyTransforms` command-line tools, so ANTs must be installed and on your `PATH`

FSL and ANTs are standalone neuroimaging toolkits, not Python packages — they are installed separately from the steps below, following each project's own installation instructions linked above. No specific version is pinned by this repository; a reasonably recent release of each should work.

## Installation

```bash
git clone https://github.com/RobinSchnabel/IROC-Public.git
cd IROC-Public
```

### Python environment

This project uses [`uv`](https://docs.astral.sh/uv/) and ships a `uv.lock` for a fully reproducible environment. With `uv` installed:

```bash
uv sync
uv run --with jupyter jupyter lab   # or: uv add --dev jupyter ipykernel, then `uv run jupyter lab`
```

Alternatively, with plain `pip`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate   # on Windows: .venv\Scripts\activate
pip install h5py matplotlib nibabel numpy pandas scikit-image scipy sphericart torch
pip install jupyterlab ipykernel
```

### FSL and ANTs

Install FSL and ANTs following their respective documentation:

- FSL: https://fsl.fmrib.ox.ac.uk/fsl/fslwiki/FslInstallation
- ANTs: https://github.com/ANTsX/ANTs/wiki/Compiling-ANTs-on-Linux-and-Mac-OS

Confirm both are visible on your shell `PATH` before running the notebooks:

```bash
which topup fslmerge
which antsRegistration antsApplyTransforms N4BiasFieldCorrection ResampleImage
```

### Launch Jupyter

Notebooks import local modules as `src.reconstruction`, `src.read_write`, `src.utils`, so Jupyter must be launched **from the repository root** so that it is on the Python path:

```bash
jupyter lab   # from the repository root
```

## Data

Raw k-space data (`data/raw/*.h5`) and the ground-truth reference scan and segmentation (`data/ground_truth/`) are included directly in this repository (together, under ~110 MB), so the full pipeline can be reproduced without any external download.

Raw files are named `position{1,2,3}_RO{inv,reg}_ES{000,200}.h5`:

- `position{1,2,3}` — one of three phantom positions in the scanner
- `ROinv` / `ROreg` — inverted vs. regular readout gradient polarity
- `ES000` / `ES200` — echo-shift condition

`data/ground_truth/` holds the high-field (3T) reference phantom scan (`phantom_MRI04_iso1mm_N4.nii.gz`), its brain/phantom mask (`Full_Phantom_Mask.nii.gz`) and its region segmentation (`LABEL_SEGMENTATION_ALL.nii.gz`), used by the ANTs-based distortion computation as the undistorted reference.

`data/image_domain_correction/` holds the `topup` configuration files (`acqparams.txt`, `b02b0_1.cnf`) needed by `3-IDC.ipynb`.

All other `data/` subfolders are intermediate/output directories, populated by running the notebooks, and are not pre-populated in the repository.

## Usage

Run the notebooks from the repository root, in order:

| Notebook | Purpose |
|---|---|
| `1-IFFT.ipynb` | Inverse-FFT-reconstructs all raw data and writes NIfTI files |
| `2-CPR.ipynb` | Runs CPR and Iterative CPR, exporting reconstructions and B0 maps |
| `3-IDC.ipynb` | Runs Image Domain Correction using FSL (`fslmerge` + `topup`) |
| `4-IROC.ipynb` | Runs the proposed IROC joint reconstruction |
| `5-Distortion_Computation.ipynb` | Calls `scripts/script_distortion_computation.py` and `scripts/script_distortion_computation_position_avg.py` (ANTs) to compute distortion metrics for every reconstruction |
| `6-Analysis1_Runtime.ipynb` … `6-Analysis4_B0Maps.ipynb` | Produce the runtime, SSH-order, distortion and B0-map tables/figures |
| `7-Images.ipynb` | Produces the remaining paper figures |

The two scripts under `scripts/` can also be run directly from the command line; see the usage example in each script's docstring (e.g. `python scripts/script_distortion_computation.py --help`).
